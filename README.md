# Hormuz Vessel Traffic

Interactive ArcGIS Maps SDK for JavaScript map of AIS vessel presence in the Persian Gulf, Strait of Hormuz and Gulf of Oman (22-30.5N, 47-62E), Jan-Oct 2026.

- Data: [Global Fishing Watch](https://globalfishingwatch.org/) AIS presence (gridded vessel-hours, monthly), AIS gap events and encounter events. Licence: CC BY-NC 4.0 (non-commercial).
- Limits: gridded data only (no ship tracks); low counts near coasts can reflect GNSS jamming; vessel-class split was unavailable from GFW at build time.
